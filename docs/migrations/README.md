# Migration guides

Every boot-mcp-doctor release has a migration guide from the release before it, even when nothing needs to change. To skip several versions, read each guide between your version and the new one, in order.

| Version | Migrating from | Migration needed? |
|---|---|---|
| [0.1.2](0.1.2.md) | 0.1.1 | No. Change the version. |
| [0.1.1](0.1.1.md) | 0.1.0 | No. Change the version; three behaviors differ. |
| [0.1.0](0.1.0.md) | — | Not applicable: the first release. |

Which Spring Boot and Spring AI versions each release works with is in [Compatibility](../compatibility.md).

New guides start from [the template](TEMPLATE.md); [RELEASING.md](../../RELEASING.md) covers when to write one.
